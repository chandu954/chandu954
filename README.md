## About

Software engineer focused on the full lifecycle of AI products — from model-level reasoning and retrieval design to the distributed systems that serve them. I build RAG pipelines with tenant isolation, multi-agent orchestration with persistent memory, and honest-AI guardrails that keep production systems reliable. The full-stack engineering is not a footnote: every AI system I ship is containerized, observability-instrumented, and deployed with the infrastructure maturity of a product, not a prototype.

- Software engineering-first approach to AI product delivery
- RAG and LLM systems engineered for scale, security, and evaluation
- Full-stack product engineering — React, Next.js, FastAPI, PostgreSQL, Redis
- AI safety and honesty as first-class system requirements
- Open source contributor and continuous learner

**Open to:** Senior Software Engineer · AI/ML Engineer · Full-Stack Engineer · LLM Application Engineer

<details>
<summary><strong>🧠 Research Swarm — Multi-Agent Research System</strong></summary>

<br/>

Multi-agent research platform that decomposes complex questions into parallel research tasks, retrieves source-grounded evidence, and synthesizes answers with explicit citations.

| Attribute | Detail |
| --- | --- |
| **Stack** | Python · LangGraph · FastAPI · React · Redis · Vector Search |
| **Scale** | Parallel agent fan-out with shared memory and task coordination |
| **Performance** | Concurrent sub-agent execution with merged, deduplicated results |
| **Security** | Source-verified outputs with provenance tracking |
| **Impact** | Production-quality research assistant replacing manual research loops |
| **Repository** | [Live Demo](https://research-swarm-omega.vercel.app/) |

The system models research as a graph: a planner agent decomposes the query, sub-agents execute retrieval and synthesis in parallel, and a critic agent validates source grounding before any claim reaches the user. Persistent memory enables multi-turn research conversations that build on prior findings.

</details>
